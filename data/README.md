# Shield datasets

Put this whole folder in `C:\shield\data`.

| File | Rows | What it is | Use it for |
|---|---|---|---|
| `shield_training_domains.csv` | 276,270 (50/50) | `domain`, `is_phishing` (1 = phishing, 0 = legit) | Training the domain classifier |
| `shield_test_domains.csv` | 10,000 (50/50) | Same columns; no overlap with training; phishing side comes only from Phishing.Database | Honest accuracy number for the pitch |
| `uae_phishing_domains_real.csv` | 66 | Real phishing domains impersonating UAE brands (Etisalat/e&, Aramex, Emirates Post, ADCB, Emirates NBD, Mashreq, payment portals, Dubai travel lures) | Replay demo, campaign clustering, pitch examples. Not in training. |
| `phiusiil_urls_labeled.csv` | 235,795 | Full URLs with `is_phishing` | Optional: URL-level experiments |
| `train_baseline.py` | — | Ready-to-run baseline model | Starting point for the ML person |
| `lists/tranco.zip` | 1M | Tranco top sites (download: `python backend\scripts\download_data.py`) | `popularity` feature |
| `lists/umbrella.zip` | 1M | Cisco Umbrella top hostnames (DNS traffic) | Real legitimate hostnames for training; 1 in 5 owners kept for evaluation only |
| `uae_holdout_frozen.csv` | grows | Analyst-confirmed UAE fakes moved out of training by `ml/retrain.py` | Untouched UAE test set |
| `sources/` | ~2M | Public phishing lists (Phishing.Database links + dated snapshots, PhishDestroy, OpenPhish), downloaded by `python ml\collect_uae.py` | Raw material for the two sets below |
| `uae_phishing_collected.csv` | ~600 | **Real** UAE-targeted phishing found in all those lists (`category`: brand / fake_ae / uae_lure / path / uae_plain), `part` = train or dev | `train` part is trained on; `dev` part is never trained on and its mistakes are inspected |
| `uae_test_frozen.csv` | ~250 | The frozen third of the real UAE phishing (by site) | **Never trained on, never inspected**: only totals are reported |
| `unseen_train.csv` / `unseen_dev.csv` / `unseen_frozen.csv` | 120k / 20k / 20k | Phishing from the new lists + legit Tranco sites ranked 250k–1M and every .ae site in Tranco, with every site from the base files removed (`python ml\build_unseen.py`) | train / inspect / frozen, like the UAE sets |
| `facts_cache.jsonl`, `facts_owners.txt` | ~4k | Looked-up domain facts (age, registrar, DNS, hosting, certificate) and the sites used for the facts model (`ml/train_facts.py`) | Facts model; these sites are kept out of the name model |
| `brand_refs/` | ~40 | Screenshots and icons of the official UAE brand sites (`python -m backend.app.pagecheck --refs`) | Look-alike check of suspicious pages |
| `evidence/<domain>/` | — | Evidence packs: report.html, screenshot.png, evidence.json | Takedown requests |

Splits are by **site** (owner): one site is always in one part only, in every file, so
nothing in a dev/frozen part can be recognised from training.

## Warnings

- **Don't trust 99% scores.** PhiUSIIL is known to be easy: its legitimate URLs are
  almost all `https://www.` and many phishing ones are not, so models learn that shortcut.
  That's why the files here are domain-only with `www.` removed, and the test set comes
  from a different source.
- **Never open these domains in a browser.** They are real phishing sites.
- Some legitimate-labelled domains may be wrong, and some phishing domains are
  compromised legitimate sites. Treat labels as mostly right, not perfect.
